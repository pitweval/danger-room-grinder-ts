# Danger Room Grinder — TypeScript

This repository is the foundation for the TypeScript implementation of Danger Room Grinder.
It currently contains project tooling and a development CLI only; no gameplay systems have
been ported.

## Prerequisites

- Node.js 24 LTS
- npm

## Install

```bash
npm ci
```

## Commands

```bash
npm run build
npm test
npm run lint
npm run format
npm run format:check
npm run drg
```

`npm start` and `npm run drg` both run the development CLI.
